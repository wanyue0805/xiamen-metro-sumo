# 地图数据来源与许可

地图数据沿用用户提供的厦门 SUMO 项目中的 OpenStreetMap 缓存；网页地图包含裁剪、简化与坐标映射后的数据。

© OpenStreetMap contributors。OpenStreetMap 数据依据 Open Data Commons Open Database License（ODbL）1.0 提供：

- 许可全文：https://opendatacommons.org/licenses/odbl/1-0/
- 来源与署名说明：https://www.openstreetmap.org/copyright

涉及 OSM 的地图数据与衍生地图数据继续遵循 ODbL。仿真列车、接驳公交、车辆段、客流、信号和车辆映射属于实验模型，不应当作实测运营或工程设计资料。

SUMO 与相关运行库的许可由其官方发行包提供；原项目已有的 LICENSE.txt 保留。
