# SUMO 网页远程控制

本机项目：`D:\sumo-web-remote`。公网入口：`https://sumo.wanyue0805.top`。

## 使用

1. 双击 `Open_Control_Center.bat` 打开启动中心。
2. 点击“启动 Windows 远程面板”。窗口标题显示网页连接状态。
3. 点击“打开网页”，使用启动中心显示的用户名、密码登录；密码可显示/隐藏。
4. 网页右上角显示仿真端已连接后，点击启动。初次加载路网约需 15 秒。
5. Windows 面板需保持运行。暂停保留状态；停止关闭当前会话；重新启动创建新仿真。

关闭网页控制连接会暂停仿真。恢复连接后点击继续；不会自动重放旧操作。本地面板仍可操作，关闭该面板会结束它持有的仿真。设备不会开放入站 TraCI 端口。

当前这台 Windows 经现有本地 HTTPS 代理访问公网域名，代理需保持可用。独立网络可用性取决于用户网络与 DNS/TLS 链路。

## 项目结构

- `agent`：Windows 连接代理、启动中心与隔离依赖。
- `simulation`：原项目的独立副本；联合引擎通过 libsumo 使用 TraCI API。
- `server`：Express/WebSocket 中继与网页。
- `config`：受本机文件权限保护的设备凭据、登录信息和本地测试配置。

原 `D:\sumo_Xiamen_v3.0`、`D:\sumo项目\sumo_Xiamen_v3.0` 与原 Metro.exe 保留。Windows 的 libsumo 入口不提供原生 SUMO GUI 联动，使用已有桌面绘图与网页地图；原项目入口继续提供原生 GUI 与独立 GIS 公交场景。新面板可独立打开不带 TraCI 的 SUMO 实景路网窗口。

实景地图的列车位置来自站间映射，信号位置来自线路映射；车辆段/折返区显示位置可能锚定到关联车站。仿真图显示模型坐标。线路、客流和车辆段属于仿真设计，不能作为实测运营资料。

## 控制语义

- 线路限速在当前线路最大速度范围内；单车速度采用 km/h，停车使用 0，恢复 SUMO 自动速度使用 -1。
- 停止增派仅停止该线路新的列车发车，在途车辆继续运行。
- 信号支持 5～900 仿真秒的红灯保持，恢复原自动闭塞程序；暂停期间不递减。
- 接驳公交为联合仿真的 B01～B04；独立 OSM GIS 公交入口仍在原项目。
- 预约入段选择第一股道，原面板可使用更完整的车辆段选项。
- 同时只有一个网页会话持有控制权；其他会话可观察。

## 服务器维护

VPS：143.246.62.51。新增服务 `sumo-web.service`，目录 `/opt/sumo-web`，配置与 TLS 证书副本在 `/etc/sumo-web`。服务使用非 root 的 sumo-web 用户；只有低端口绑定能力，内存硬上限 160 MiB。Node 是独立运行时，没有替换系统运行环境。

证书由 Let's Encrypt 签发。`certbot.timer` 使用本项目隔离的新客户端续期；HTTP-01 验证期间临时使用 80。部署钩子只处理 sumo.wanyue0805.top 的证书，复制受限文件并重启新增中继服务。续期重启可能暂停当前远程仿真，重新连接后显式继续。

服务器现有 3x-ui/Xray、Marzban/Xray、Docker 和 fail2ban 保留。不能删除其配置、容器、数据卷、证书或原防火墙规则。

回滚时，仅停用新 `sumo-web` 服务并关闭新 Windows 面板；原桌面入口可继续使用。按需要撤销带 sumo-web 注释的 80/443 新规则。不要恢复整份防火墙快照或删除其他服务。保留当前证书客户端与续期配置，除非同时停用本项目的证书维护。
