# 2026年10月21日：修复实景图列车反向闪现

## 已确认的原因

列车实际运行位置正常，但旧版GeoMap.train_point仅在普通站间轨道上计算连续的地理位置；进入站台、内部连接、折返连接或跳停区段后，会用train.station定位。这个字段表示最后实际停靠站，直到停车才更新，并不代表当前所在位置。

实际复现：L1-U-001从L1_GU02进入L1_U03时，物理位置向前移动11.11米，实景位置却反向跳动1163.87米；停车时物理位置不动，实景位置又跳到本站。另一列车L2-D-002在同一站台同一坐标，因停靠站字段更新而产生1141.73米的显示跳动。

网页动画另有两处放大跳变的逻辑：网络数据到达间隔不均匀时，动画从前一个目标位置重新开始；同一会话中的较早时间状态可能覆盖较新状态。

## 修复方式

1. 从列车当前实际轨道的起终点确定所属站点，用该轨道上的实际行驶进度映射地理位置。覆盖普通站间轨道、站台、内部连接、两端折返连接、车辆段与出入段。当前位置不再依赖最后停靠站。
2. 平台及内部连接锚定本站，跳停经过也不会退回上一站；始发与终到连接按真实方向连续推进。
3. 网页新动画从当前已经显示到的位置接续；同一仿真会话拒绝时间倒退的数据。重复传输不刷新冻结数据的新鲜度，重置会话按新会话状态处理。
4. 保留暂停和数据过期时的停止显示规则，不向未来推算。真实终点折返仍然保留。

本次调整的是地理显示与网页状态衔接，未改变列车物理轨道、限速、停站、闭塞、发车间隔或乘客换乘规则。城市地理图仍是模型到站点的示意映射，不是实测轨迹。
