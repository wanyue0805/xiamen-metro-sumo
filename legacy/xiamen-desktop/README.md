# 厦门综合交通仿真 3.0

当前项目版本：**3.0**（整理发布：2026-10-14）  
项目目录：`F:\SUMO_Xiamen_Subway`

## 这一版包含什么

这是对现有项目的统一命名和归档整理，主体采用原4.1交付内容，版本名按你的要求定为3.0。程序、路网、地图和参数均保留；运行标题和性能报告版本同步为3.0。

- **五线地铁联合仿真**：1、2、3、4、6号线共用 SUMO 时钟，保留原调度、折返、客流和换乘逻辑。
- **厦门实景地理底图**：OSM道路、水系、海岸线与地铁数据；提供地图浏览和独立GIS公交演示。
- **接驳公交与客流**：联合场景含四条演示接驳线，公交与轨道按同一仿真时钟运行；聚合客流点以20人为一组显示，末组保留实际人数。
- **轨道信号控制**：可对信号限时控制并恢复自动运行。
- **车辆段场景**：十处仿真车辆段、三十条存车/整备股道；支持列车回段停放和整备后出段。
- **界面与运行优化**：四个功能页、车辆段近景、地图缓存和限时批量仿真推进。

| 文件 | 用途 |

| `Metro.exe` | 打开综合控制面板 |

## 版本归档

项目最初的五线联合仿真名称为3.0；随后曾以3.1记录地图和界面改动，4.0记录OSM路网、公交、客流和信号扩展，4.1记录车辆段和性能优化。现在按你的要求，把当前完整项目正式统一命名为**3.0**。旧编号只保留在对应历史说明、报告和早期测试数据中，用于识别其生成时间与测试范围，不代表当前功能缺失。

历史说明已改名为 `历史_4.0综合交通升级记录.md` 和 `历史_4.1车辆段与流畅度升级记录.md`。早期3.0/3.1内容也保留在本文件底部的 `README.md` 历史说明区，不影响运行。

## 仿真边界

OSM底图来自真实地理数据，但既有地铁运营模型、接驳线路、车辆段位置与配线、时刻表和客流均属于仿真设计或演示，不应当作官方现行运营图或工程实测方案。洗车、检修建筑用于场景展示，没有独立的洗车或维修作业流程。

细节与验证：`历史_4.1车辆段与流畅度升级记录.md`；原始升级报告和数据仍保留在 `logs` 及此前的交付归档中。
